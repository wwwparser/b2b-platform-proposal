# Предложение по реализации B2B-платформы ЖБИ

Статический HTML-сайт с предложением: уровни запуска, сценарий, этапы, М1–М11, оценки, архитектура, приёмка, эксплуатация и О1–О15.

Сайт: https://wwwparser.github.io/b2b-platform-proposal/

Интерактивный прототип: https://wwwparser.github.io/b2b-platform-proposal/demo/

Оценки предварительные. Демонстрация использует синтетические данные; ИИ, платежи и внешние рассылки не подключены.

Для локального просмотра: `python -m http.server 8137 --bind 127.0.0.1` из корня репозитория.

Публикация GitHub Pages: ветка `main`, корень `/`. Сборка и зависимости не нужны. Исходные документы заказчика, его контакты и локальные исследовательские файлы в этот репозиторий не включены.
